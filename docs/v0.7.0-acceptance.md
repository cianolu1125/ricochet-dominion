## Review corrections

1. Extend own-turn sampled paths with the chosen follow-up and settlement; compare complete actual samples to the complete ideal horizon.
2. Replace two-segment opponent prediction with bounded atomic relay chains plus remaining turn actions. Reserve branch budget across relay depth.
3. Explicit controller stop clears its PvE session, preventing a new search on an old Blue-turn state.
4. Credit pending contested ownership to the incoming captor, discounted by defender proximity, rather than valuing only the original owner. Actual ownership and rules remain unchanged.
5. Replace the blanket Hard maturity multiplier with bounded per-outpost unused growth capacity, respecting board bounds and enemy protection. Already mature structures receive no invented structural growth; future value vanishes at the round limit.
6. Paired lab mode uses the same seed on both side assignments. The invariant runner now checks relay uniqueness, charge history, inactive protection, dynamic pending sources/membership and recomputed control/connection maps.

7. Replace late Hard HP-first behavior with the engine’s area/HP/outpost score order for the final two rounds, while retaining terminal kill/loss priority. A valid-state regression fails without this correction and passes with it.

## Physical-device boundary

Automated phone layouts and real Chrome execution are verified. This environment provides no physical iOS/Android device and no audible sound monitoring; real device touch comfort, audible sound quality, battery/thermal behavior and device FPS cannot be certified here. These are explicitly unverified, never represented as passed. Reduce Motion and audio lifecycle behavior remain covered by automated tests. A bounded Worker timeout is a search safety cutoff; it is recorded separately from an illegal state or stuck match.

## Release gate

Do not merge a partial tree, omit tests/documents, or publish a build made from another snapshot. Compare Git blob hashes across all tracked files, verify package version 0.7.0, confirm zero rule-file changes, and retain raw strength/flow metrics. A clean automated suite is necessary but does not by itself establish every quality criterion above.
