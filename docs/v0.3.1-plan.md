# v0.3.1 UI Refinement

## Scope

Keep engine.js and physics.js unchanged. Replace the old floating menu container with independently positioned branch nodes connected to the current vanguard. Fit the complete board into the full canvas using a four-pixel rim and overlay the HUD. Unify surfaces with dark navy, geometric shapes, fine outlines and the battlefield's red/blue highlights.

## Branches

Root: vanguard to Move and Action. Action: vanguard to the Back junction, then three independent leaves (Fire, Build/Redeploy Outpost, Destroy Outpost). Returning collapses the secondary branches. Selection menus retain direct board selection. Twenty-four inward fan directions are evaluated for edges and HUD exclusion; targets stay at least 44 pixels high and do not overlap. English label widths are accounted for. SVG links are cached per geometry so the animation is not restarted by every rendering frame.

## Turn handoff

End Turn uses the existing rule layer and enters HANDOFF. Ready hides the pass-device overlay. Touch profiles rotate for 400 ms without calling beginTurn. At the completed orientation, beginTurn executes exactly once and its visual diff starts. Input, menu and End Turn stay locked for the 520 ms settlement presentation. Desktop skips rotation but uses the same settlement lock. Reduced motion skips rotation and uses at least 100 ms and waits for every actual settlement effect to complete. Player input cannot interrupt or settle the turn twice.

## Camera

Full canvas is aspect-fit with four-pixel rim, without subtracting the dock height. Square grid cells and world coordinates are preserved; the entire map remains visible. Aspect ratio mismatch may leave space on the unconstrained axis. HUD is an overlay, not a reserved board strip. Browser and OS chrome remain outside the page.

## Validation

Automated coverage includes default and edge fans, five responsive profiles, four-pixel camera fit, rotation-before-growth, settlement input lock, cancel, relay, bilingual state preservation and the existing engine/physics suite. This environment has no Sites control-browser skill: DOM/geometry regression is not a substitute for real mobile visual/touch QA.
