# 弹射战线 · RICOCHET FRONT

**v0.5.0** · 同设备本地双人 PvP。手机／平板热座旋转；桌面固定视角。权威开发规格：[确认版 TXT](docs/specs/v0.5.0-confirmed.txt)。历史版本规则见 CHANGELOG。

## 当前玩法

- 每回合「移动」「行动」各一次，顺序自由。行动为飞弹、建立／重新部署据点或摧毁据点。五据点上限包含出生据点。
- 在战场任意位置向后拖拽、松手弹射。真实撞到己方据点实体才捕获、重新瞄准发射；出生据点参与中继，源据点发射不计中继。先锋与飞弹的中继记录独立。同一飞弹每个据点 ID 只捕获一次，之后反弹。
- 飞弹捕获不同据点 1／3／5 次达到 Charge Ⅰ／Ⅱ／Ⅲ。基础与全部等级均可携带先锋。基础落点 3×3；Ⅰ 扩张 5×5；Ⅱ 切割 3×3＋整行整列；Ⅲ 清洗 5×5＋整行整列，并可直接撞击攻城。十字跳过敌方保护格、继续传播，不造成区域 HP 伤害或远程攻城。
- 双方 10 HP。首次直接碰撞先读目标脚下颜色，是目标己色则 −1；携带每次非己色→己色再 −1。保护仅保护土地。HP 归零立即终止剩余释放、攻城及染色。
- 携带者在己塔捕获、攻城或最后落点释放时，沿实际入射线选择合法位置，先按变化前地图判伤。直接命中共享据点格的先锋先处理先锋碰撞，存活才继续攻城。
- 己色四连通至己塔为稳定领地；断联颜色为临时领地。面积包括两者。敌方临时区域内建塔启动争夺，对手有一完整回合抢救。新接入临时格立即纳入争夺，建塔方下一回合开始按当时整个临时连通块结算；分裂继承原截止时间，恢复稳定部分退出，所有来源消失则取消。
- 新生据点按己方回合开始成长 1×1→3×3→5×5。先结算争夺再成长。成长仅染色未受保护格；同色多据点保护区取并集，拆掉一个后仍被其他据点覆盖的格继续受保护。重新部署移除旧塔、保留旧颜色，新塔从 1×1 起步。
- 取消中继瞄准保留已提交链；主动结束回合在捕获点按当前等级结算。完整轮末达到 80% 获胜；10／14／18 或自定义 1–100 轮后依次比较面积、HP、塔数，同分直接平局。

## 界面与反馈

顶部进度轨按当前己方据点数显示 0–5 个节点，实际中继读数始终 R/5。1／3／5 为菱形，2／4 为圆形；无框技能名随进度轨淡入淡出。轨道与战场共享拖拽输入。先锋旁使用单列等宽行动按钮、单根连接线及 44px 返回节点。

保留简洁深色科技风，保护区外轮廓、临时纹理、慢速争夺脉冲。真实反弹各有短火花和音效；伤害 20ms、攻城 40ms 打击停顿，不叠加、不补算物理时间。因果同组只播放一次主声音／主抖动，独立真实事件保留。Web Audio 使用短柔和合成音、压缩、最多 8 个活跃音效；后台与退出清理，恢复／中断／关闭音频上下文独立处理。音量、音效和减少动效偏好独立持久化。

## 开发与验证

Node 20.19+ 或 22.12+。`npm ci`、`npm run dev`。检查：`npm test`、`npm run check`、`npm run build`；静态产物 `dist/`。

- `engine.js`：领地、成长、保护并集、回合结算；`claims.js`：动态争夺成员；`charge.js`：等级与染色目标。
- `physics.js`：连续碰撞、中继、逐格携带判伤和释放；`view.js`：四种固定地图配置及可逆视角。
- `main.js`：输入、菜单、对局生命周期；`relay-hud.js`：只读取规则状态的进度展示。
- `renderer.js`／`effects.js`／`visual-changes.js`：Canvas 与真实规则结果动效；`feedback.js`／`audio.js`：因果反馈和音频生命周期。

122 项自动测试覆盖四种配置整局、五种视口 DOM 操作、动态争夺增补／分裂／抢救、保护重叠、所有等级真实落点、致命中止、中继菜单与键盘、低帧率停顿恢复、音频资源上限及 100 轮受控状态压力。原生 Canvas 快照检查覆盖保护、十字与攻城。压力测试使用受控合法场景，不等于持续人类游玩。当前环境未提供 Sites 要求的实时游戏浏览器 QA 技能；iOS／Android 真机触感、设备帧率与音色听感仍需实机验证。
