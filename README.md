# 弹射战线 · RICOCHET FRONT

**v0.3.1-ui-refinement** · 同设备本地双人 PvP。手机与平板采用热座旋转；桌面固定红左蓝右。无电脑对手、账号、联网、数据库或对局存档。

## 玩法

- 每回合有一次「移动」和一次「行动」，顺序自由，也可跳过。移动为弹射；行动选择发射、建立／重部署据点或摧毁据点。结束回合放弃剩余资源。
- 在战场任意位置向后拖拽，松手发射。移动、飞弹及两种中继使用相同拖拽方式。发射后不可撤销。中继后取消只清除瞄准、保留中继；主动结束回合按已有停止规则落下先锋／引爆飞弹并交接回合。
- 己方颜色通过上下左右连通至任意己塔为稳定领地，否则为断联区。临时颜色不会自然消失；面积计分包含全部本方颜色。
- 在敌方断联区建塔后，记录原连通块快照。对手有完整一回合抢救；建塔方下一回合开始时，仍为敌方断联区的快照格被吞并。来源塔全部移除则取消吞并。
- 每方最多五塔，出生塔计入上限且初始为 5×5。新塔按拥有者回合开始成长 1×1→3×3→5×5；先获得的敌方保护优先。重部署保留旧地颜色但移除旧塔供给和独占保护。
- 先锋移动中每座己塔最多捕获一次；先锋中继不消耗飞弹中继。敌塔／敌人／边界反弹；双方先锋与敌塔不能静止同格。
- 每座己塔每个己方回合捕获飞弹一次，之后仅反弹。Charge I 携带敌人；II 为 5×5 爆炸；III 可击毁敌塔。更多不同塔可以继续中继，Charge 上限 III。
- 双方 10 HP。飞弹首次碰撞时先读目标脚下颜色，是目标自己颜色才 -1；携带时每次非己色→己色再 -1，连续同色不重复。据点只保护土地。没有重生、先锋保护、近战或皇后移动。
- 红方飞弹被红塔捕获时，携带的蓝王沿入射路径反向落在塔前最近合法格；重发需真实碰撞才能再捕获。攻城先移除塔和独占保护，重算连通，再 5×5 爆炸和重算。
- HP 归零立即结束。完整轮末达到 80% 获胜；10／14／18 轮后比较面积、HP、塔数。完全同分加时一轮，比较净领地变化，仍相同为平局。

## 开发与验证

Node 20.19+ 或 22.12+。`npm ci`、`npm run dev`。完整检查：`npm test`、`npm run check`、`npm run build`。产物 `dist/`。

`engine.js` 负责领地、塔和回合规则；`physics.js` 负责共享弹射、连续碰撞及逐格携带判伤；`view.js` 负责锁定地图配置与可逆视角；`renderer.js` 绘制几何战场；`main.js` 绑定先锋旁菜单、底部 HUD、取消区和输入。默认参数集中在 `config.js`。

地图配置在开局时锁定：手机 18×32、平板竖屏 24×32、触屏横屏 32×24、桌面 32×18。视口变化只缩放显示；采用等比 aspect-fit，不拉伸圆形和反射角。支持 safe-area、减少动效偏好、键盘操作菜单和相对拖拽。

自动测试覆盖规格 T01–T34 核心规则，以及四种配置整局、五种视口 DOM 操作、保护区重叠、加时、精确格子穿越和帧率一致性。DOM 测试不等同于 iOS／Android 真机测试；本次环境未提供合规的实时游戏浏览器 QA 能力，真机触感与浏览器视觉仍待实测。

## v0.3.0 UI & Theme Update

- 开局在先锋旁自动展开「移动／行动」。移动直接瞄准；行动展开发射、建立据点、摧毁据点、返回。可建据点直接建立，可摧毁一个据点直接执行，多目标才选择。
- 瞄准时底部 HUD 切换为取消区。未拖动可点击返回；拖动后进入取消区松手取消。不消耗尚未提交的资源；中继取消不回退、不停止、不引爆。
- Canvas 全屏，地图镜头等比适配底部信息层，保留系统手势边距。结束回合始终在右下；对手信息可展开／关闭。菜单随先锋位置调整且避开 HUD。
- 简体中文／English 在设置中即时切换，不重置对局，保存到 `ricochet.language`。全部玩家文案集中在 `src/i18n.js`。
- 每次伤害独立显示 −1 HP，原地闪烁；领地翻色、断联／恢复、据点成长、摧毁和中继提供短反馈，支持减少动效。
- 新手教程与人机对战显示 Coming Soon，为真正禁用入口。本版仍仅支持本地双人。
- 规则层 `engine.js` 与 `physics.js` 原样保留。65 项自动测试通过，覆盖既有规则、五种视口的 UI、取消与中继、语言、回合交接和设置返回。生产构建与语法检查通过。
- 当前运行环境缺少 Sites 指定的 control-browser 技能，未执行真实浏览器布局／真机触感测试。DOM 与镜头测试不替代真实手机验证。

## v0.3.1 UI Refinement

- 先锋原点 → 移动/行动 → 行动选项的独立节点与连接线；边缘自动向内展开。
- 全屏 Canvas，地图以 4 CSS px 细边框进行最大等比适配，HUD 覆盖其上。
- 热座交接：旋转结束后才 beginTurn；结算动效完成后才解锁操作。
- 首页、设置、HUD、取消区统一深色科技风、细描边与阵营高亮。
- 核心规则与物理逻辑保持不变。
